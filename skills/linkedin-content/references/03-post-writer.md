# Skill: Post writer

1. Write one sentence stating the post's central argument before drafting.
2. Select a shape that fits the material: chronological story, workflow breakdown, decision memo, opinion with evidence, field note, or comparison.
3. Use concrete nouns and operational verbs.
4. Preserve useful tool names and technical terms, but explain why the decision matters.
5. Vary paragraph length and information order across posts.
6. Stop when the argument lands. Add a question only when it invites informed responses.

Default LinkedIn output should be easy to scan on mobile without becoming a ladder of sentence fragments.
