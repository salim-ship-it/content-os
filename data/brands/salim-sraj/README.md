# Salim Sraj content workspace

This is the first active brand workspace in Content OS.

The files separate identity, voice, audience, pillars, verified evidence, and publishing guardrails so generation does not depend on one oversized prompt. `CONTENT_OS_BRAND` can select another workspace later; it defaults to `salim-sraj`.

Only claims marked `approved` and `publiclyShareable` in `evidence.json` may be presented as fact without asking Salim for confirmation.

`performance.json` starts empty and is the canonical place for connecting each published post to its hook, format, topic, and results.
