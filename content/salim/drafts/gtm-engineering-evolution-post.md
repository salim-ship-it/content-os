# The Evolution of GTM Engineering — LinkedIn Post

**Hook formula:** "Claude Code has 3 levels. / Most people never get past the first." — Charlie Hills, 1,441 likes (library: posts-export.json)

---

GTM engineering has 4 levels.

Most teams are stuck on the second.


My first GTM job was 90% tabs and 10% thinking.

Now it's the other way around.

Same buyers. Same lists. Same targets.

I just stopped being the thing that runs.


LEVEL 01 - MANUAL

✦ Find companies, copy data, open LinkedIn tab by tab

✦ Clean the sheet, qualify by hand, write every line yourself


You are the workflow.


LEVEL 02 - AUTOMATION

✦ Trigger → scraper → enrichment → CRM → outbound → Slack

✦ You stop running steps and start wiring them


Most teams retire here.


LEVEL 03 - ORCHESTRATION

✦ One surface holds the logic: Clay, or open-source builds like YALC

✦ Source → enrich → research → verify → route

✦ Nothing got replaced. The providers moved behind one workflow


LEVEL 04 - CODING AGENTS

✦ Clay ships an API, a CLI and MCP. YALC runs inside Claude Code

✦ ColdIQ open-sourced hooks that fire into Apollo, Instantly and the CRM

✦ The agent sits on top and writes the logic between them


Access alone just gets you faster automation.


The unlock is context.

✦ Your ICP, positioning, pricing, objections

✦ Call recordings, closed-won reasons, CRM history

✦ What past campaigns actually did


Load that once and the agent stops guessing.

It builds what fits your business.


Not every GTM engineer walked this path. The tooling did.


Level 4 isn't "the agent replaces the platform."

Your orchestration layer still owns the data.

The CRM still owns the record.

The agent owns what gets built on top.


→ doing tasks

→ automating tasks

→ orchestrating systems

→ handing an agent the keys and the context


The tools stopped being the hard part.

Knowing your business well enough to describe it is.


P.S. Which level are you actually on?
