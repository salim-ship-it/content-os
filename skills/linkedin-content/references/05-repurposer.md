# Skill: Repurposer

Preserve the source claim and evidence while changing the delivery mechanism.

- **Carousel:** one promise, one idea per slide, evidence before conclusion.
- **Short video:** spoken language, early tension, concrete visual proof, no essay-style introduction.
- **Newsletter:** add context, implications, and implementation detail rather than padding.
- **Follow-up posts:** isolate genuinely different sub-ideas instead of paraphrasing the original.
- **Quote card:** use an original Salim line that can stand alone without losing its meaning.

Always retain a reference to the source idea so later performance can be compared across formats.
