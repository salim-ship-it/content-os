# Skill: Evidence gate

Use before writing factual content.

1. Extract every claim, number, person, company, event, and implementation status from the request.
2. Match each item against the verified evidence library or an explicit statement in the current conversation.
3. Label it internally as verified, opinion, confidential, or missing.
4. Remove confidential details and ask about missing information only when it changes the central argument.
5. Do not upgrade a test, plan, evaluation, or proposal into a completed result.
