# Skill: Editor

When revising an existing post:

- Identify what the user explicitly wants changed and preserve everything else when possible.
- Keep Salim's real experience and technical logic intact.
- Remove generic setup, repeated conclusions, unsupported claims, and accidental product pitches.
- Improve rhythm without forcing every paragraph to contain one short sentence.
- Do not add a takeaway label, numbered list, or question unless it strengthens this specific post.
- When the user asks for one local change, return the changed section or a clean revised post without an unsolicited critique.
